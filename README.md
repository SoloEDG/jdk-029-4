# 夜航练习室

## 本地启动

```sh
npm ci
npm run dev
```

在浏览器打开 Vite 输出的本机地址。麦克风需要本机地址或 HTTPS。

## Docker 启动

```sh
docker compose up --build
```

打开 <http://localhost:8029>。可以通过 `NIGHT_SESSION_PORT` 指定其他端口。

## 会跟唱的导唱

练习时导唱先试听同一句，再从弱起进入。你及时唱上来，导唱立刻让出后面的旋律；
漏唱时它等到下一处适合接入的换气点再提示。

- **重音处的两个接入候选**：`弱起`从音头开始，`元音`越过开头辅音、落在元音上。
  两者时钟位置不同，界面并排列出；若该音是突然拔高的一截，`元音`候选会标为不可用。
- **只播完整提示**：句末只剩半个音、或剩余时间不足一个提示时，导唱宁可不唱，
  也不会把半个辅音或一截唱腔塞进来；跳过原因写进导唱进程。
- **按证据判断**：只有持续、平稳的歌声才算接唱；短促冒尖和抖动会被记为“判不清”，
  随后仍从下一个能完整播出的预设开始。
- **拖动、循环、回跳**：拖到句中从下一个完整提示接入；循环或回跳后重新确认，
  不沿用上一遍的判断。伴奏与歌词始终照常走。
- **回顾重现实际播过的提示**：每条录音保存了导唱真正出声的事件，
  回放时按原时长重现，包括被让位截短的那一截。

`npm test` 覆盖漏唱后抢拍恢复、句末半个音和再次回跳等场景。
